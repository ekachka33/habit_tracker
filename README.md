
Habit Tracker Backend API (Курсовой Проект)
Описание Проекта
Этот проект представляет собой бэкенд-часть SPA (Single Page Application) для трекера полезных привычек, вдохновленного книгой Джеймса Клира «Атомные привычки». Приложение позволяет пользователям создавать, отслеживать и управлять своими полезными и приятными привычками, а также получать напоминания через Telegram.

Основной Функционал
Управление Пользователями: Регистрация и авторизация пользователей с использованием JWT-токенов (djangorestframework-simplejwt).

Создание и Управление Привычками:

Создание привычек с полями: пользователь, место, время, действие, признак_приятной_привычки, связанная_привычка, периодичность, вознаграждение, время_на_выполнение, признак_публичности.

Полный CRUD (Create, Retrieve, Update, Delete) для привычек.

Валидация Привычек: Реализованы сложные валидаторы в сериализаторах и моделях для обеспечения бизнес-логики:

Нельзя одновременно иметь вознаграждение и связанную привычку.

Время выполнения не более 120 секунд.

Связанная привычка может быть только приятной.

Приятная привычка не может иметь вознаграждения или связанной привычки.

Периодичность от 1 до 7 дней.

Для полезной привычки должно быть указано либо вознаграждение, либо связанная привычка.

Пагинация: Реализована пагинация для списка привычек (по 5 привычек на страницу).

Права Доступа:

Каждый пользователь имеет полный доступ (CRUD) только к своим привычкам.

Авторизованные пользователи могут просматривать список публичных привычек других пользователей.

Интеграция с Telegram: Отложенные задачи через Celery для отправки напоминаний о привычках в Telegram.

CORS: Настроены заголовки CORS для корректной работы с фронтендом.

Документация API: Автоматическая генерация интерактивной документации API с использованием drf-yasg (Swagger/Redoc).

Переменные Окружения: Чувствительные данные (например, SECRET_KEY, TELEGRAM_BOT_TOKEN, URL для Celery) хранятся в переменных окружения.

Тестовое Покрытие: Проект покрыт юнит-тестами с высоким процентом прохождения.

Установка и Запуск Проекта
Для установки и запуска проекта следуйте следующим инструкциям:

Клонирование Репозитория:

git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ_НА_GITHUB>
cd habit_tracker


Создание и Активация Виртуального Окружения:

python -m venv .venv
source .venv/bin/activate  # Для Linux/macOS
# .venv\Scripts\activate   # Для Windows


Установка Зависимостей:

Сначала создайте файл requirements.txt:

pip freeze > requirements.txt


Затем установите все зависимости:

pip install -r requirements.txt


Настройка Переменных Окружения:

Создайте файл .env в корневом каталоге проекта.

Добавьте следующие переменные, заменив ВАШ_... значения на актуальные:

SECRET_KEY='<ВАШ_СЕКРЕТНЫЙ_КЛЮЧ_ДЛЯ_DJANGO>'
CELERY_BROKER_URL='redis://localhost:6379/0' # Или ваш URL Redis
CELERY_RESULT_BACKEND='redis://localhost:6379/0' # Или ваш URL Redis
TELEGRAM_BOT_TOKEN='<ВАШ_ТОКЕН_TELEGRAM_БОТА>'


Настройка Базы Данных:

Удалите старые файлы базы данных (если они есть) и кэш:

rm db.sqlite3
find . -name "*.pyc" -exec rm {} \;
find . -name "__pycache__" -exec rm -rf {} \;


Выполните миграции базы данных:

python manage.py makemigrations
python manage.py migrate


Создание Суперпользователя (для доступа к админ-панели):

python manage.py createsuperuser


Следуйте инструкциям в терминале для создания логина и пароля.

Запуск Приложения
Для полноценного запуска всех компонентов проекта вам потребуются 3 отдельных терминала (или процесса):

Запуск Django-сервера:

В первом терминале (с активированным виртуальным окружением):

python manage.py runserver


API будет доступно по адресу: http://127.0.0.1:8000/api/

Админ-папанель: http://127.0.0.1:8000/admin/

Документация API (Swagger): http://127.0.0.1:8000/swagger/

Документация API (Redoc): http://127.0.0.1:8000/redoc/

Запуск Celery Worker:

Во втором терминале (с активированным виртуальным окружением):

celery -A config worker -l info


Запуск Celery Beat (Scheduler):

В третьем терминале (с активированным виртуальным окружением):

celery -A config beat -l info


Убедитесь, что у вас запущен Redis-сервер, так как он используется в качестве брокера Celery (по умолчанию redis://localhost:6379/0).

Тестирование
Проект покрыт тестами для обеспечения корректности работы всех компонентов. Чтобы запустить тесты:

Убедитесь, что все серверы Django и Celery остановлены (если они запущены).

Перейдите в корневой каталог проекта.

Удалите файл db.sqlite3 и кэш, затем выполните миграции (как описано в пункте "Настройка Базы Данных" выше). Это важно для чистоты тестовой среды!

Запустите тесты:

python manage.py test


Все 42 теста должны пройти успешно (появится сообщение "OK").

Интеграция с Telegram (важно для проверки напоминаний)
Для проверки функции напоминаний через Telegram:

Получите свой Telegram chat_id:

Откройте Telegram и найдите бота @userinfobot или @JsonDumpBot.

Напишите ему /start (или любое сообщение). Бот в ответ пришлет информацию, включая ваш chat_id. Скопируйте этот числовой ID.

Добавьте chat_id в привычку:

После регистрации пользователя и запуска Django-сервера, войдите в Django Admin (http://127.0.0.1:8000/admin/).

Создайте новую привычку (или отредактируйте существующую) и в поле telegram_chat_id вставьте ваш скопированный chat_id.

Убедитесь, что is_pleasant для этой привычки установлен в False (напоминания отправляются только для полезных привычек).

Установите time привычки на ближайшее время, чтобы быстро протестировать напоминание.

Проверьте напоминание:

Убедитесь, что celery worker и celery beat запущены.

Celery Beat будет периодически (по умолчанию каждые 10 секунд) запускать проверку привычек. Когда придет время, вы должны получить уведомление в Telegram.

Прочие Утилиты
flake8: Проект придерживается стандартов качества кода. Для проверки используйте:

flake8 --exclude=migrations
Ожидается 100% прохождение (отсутствие ошибок).

# Проект Habit Tracker

## Описание проекта

Этот проект представляет собой веб-приложение для отслеживания привычек, разработанное на Django. Он позволяет пользователям создавать, отслеживать и управлять своими ежедневными и еженедельными привычками, помогая формировать полезные рутины и достигать личных целей.

## Функционал (Примерный)

* **Создание привычек**: Возможность добавлять новые привычки с описанием, частотой (ежедневно/еженедельно) и целью.
* **Отслеживание выполнения**: Простая система отметки выполнения привычки.
* **История выполнения**: Просмотр истории выполнения привычек.
* **Пользовательская аутентификация**: Регистрация, вход/выход, управление профилем.
* **Административная панель**: Управление привычками и пользователями через встроенную админ-панель Django.

## Технологии

* **Backend**: Python, Django
* **База данных**: SQLite (по умолчанию, можно настроить PostgreSQL/MySQL)
* **Frontend**: HTML, CSS, JavaScript (или используемые вами фреймворки/библиотеки)
* **Управление зависимостями**: pip, pip-tools (если используется)
* **Управление версиями**: Git
* **Виртуальное окружение**: venv

## Установка и запуск

Следуйте этим инструкциям, чтобы запустить проект локально.

### Требования

* Python 3.x
* pip

### Шаги установки

1.  **Клонируйте репозиторий:**
    ```bash
    git clone [https://github.com/ekachka33/habit_tracker.git](https://github.com/ekachka33/habit_tracker.git)
    cd habit_tracker
    ```

2.  **Создайте и активируйте виртуальное окружение:**
    ```bash
    python3 -m venv .venv
    source .venv/bin/activate  # Для macOS/Linux
    # .venv\Scripts\activate  # Для Windows (в CMD)
    # .venv\Scripts\Activate.ps1 # Для Windows (в PowerShell)
    ```

3.  **Установите зависимости:**
    ```bash
    pip install -r requirements.txt
    ```
    *Примечание: Если у вас нет файла `requirements.txt`, создайте его, выполнив `pip freeze > requirements.txt` после установки всех необходимых библиотек (Django, djangorestframework и т.д.).*

4.  **Выполните миграции базы данных:**
    ```bash
    python manage.py migrate
    ```

5.  **Создайте суперпользователя (для доступа к админ-панели):**
    ```bash
    python manage.py createsuperuser
    ```
    Следуйте инструкциям в терминале для создания логина и пароля.

6.  **Запустите сервер разработки:**
    ```bash
    python manage.py runserver
    ```

Теперь вы можете открыть проект в браузере по адресу: `http://127.0.0.1:8000/`
Админ-панель доступна по адресу: `http://127.0.0.1:8000/admin/`
